# Atlas Onírico

Generador bilingüe (español / inglés) de ideas para ilustrar: criaturas, entes, paisajes y arquitecturas surrealistas de sueño y pesadilla.

- Cinco modos: Criatura, Ente, Paisaje, Estructura y Chispa.
- Tono (sueño ↔ pesadilla) y nivel de rareza.
- Rasgos bloqueables: fija lo que te guste y vuelve a generar el resto.
- Notas para dibujar: composición, luz, técnica, referencia pictórica y paleta.
- Prompt para IA en español o inglés.
- **Ilustrar**: botones que copian el prompt y abren generadores gratuitos (ChatGPT, Bing Image Creator, Gemini, Ideogram, Leonardo), o generación dentro de la página con tu propia clave de API (Pollinations, OpenAI o fal.ai).

La clave de API se guarda solo en el `localStorage` de tu navegador; nunca se sube al repositorio.

Es una página estática (un solo `index.html`), sin dependencias ni compilación. Se publica con GitHub Pages desde la rama `main`, carpeta raíz.
